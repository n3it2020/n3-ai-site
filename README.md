# n3 ai, by N3 IT Solutions - website

Static website for n3 ai (n3cloudsolutions.com). Plain HTML, CSS and a little JavaScript. The files in this repository are the site; there is no build step.

- `index.html`, `ai-solutions/`, `industrial-iot/`, `how-it-works/`, `about/`, `contact/`, `privacy/`: pages
- `assets/`: styles, script, fonts (IBM Plex Sans, SIL Open Font License) and logo files
